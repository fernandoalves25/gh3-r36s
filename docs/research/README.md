# Pesquisa para o 3D

Anotações feitas a partir da versão de navegador (`index.html`) e conferidas nos dados do jogo, para a próxima etapa do
executável 3D. Nenhum arquivo do jogo está aqui: só a descrição dos formatos e de como o jogo os usa.

- [band.md](band.md): os roqueiros e a plateia (malhas `.skin`, animações `.ska`, esqueleto, escolha da animação por
  momento da música, posição no palco, custo no R36S). Os leitores de referência em Python estão em `tools/research/`.
- [stage.md](stage.md): câmeras e cortes por música, o show de luzes, pirotecnia e o que cada tipo de entrada dos PAKs
  de palco guarda.
